# Hall Booking Deployment Kit

Ovaj paket je priprema za puštanje aplikacije u rad uz Supabase + Vercel.

## Sadržaj
- `app/` — poslednji statički demo prototip
- `supabase/schema.sql` — starter baza, RLS pravila i audit log
- `supabase/seed-users-template.sql` — šablon za profile korisnika
- `.env.example` — env varijable
- `vercel.json` — osnovna Vercel konfiguracija
- `GO-LIVE-STEP-BY-STEP.md` — redosled puštanja u rad
- `PRODUCTION-CHECKLIST.md` — finalna kontrolna lista

## Napomena
Ovaj paket **nije potpuno završena produkcija** jer demo frontend još koristi lokalne podatke. Ali daje ti sve što treba da development tim završi poslednji korak do stvarnog rada.
